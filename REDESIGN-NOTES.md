# ELYAS AL SHAEBI — 2D editorial redesign

## Direction

- Uses the approved ivory, deep petrol and copper identity without changing the official logo assets.
- Removes the oversized fake-3D emblem, orbiting lights, faux depth layers and emoji-like controls.
- Replaces them with a lightweight, responsive 2D code-editor illustration, restrained motion and consistent inline SVG icons.
- Arabic typography uses IBM Plex Sans Arabic (Google Fonts), Noto Sans Arabic and system fallbacks, with **no negative letter spacing on Arabic glyphs**. English uses Inter.
- Includes both official primary and reverse logo variants for light and dark mode.

## Inspired by archived personal site

Brings forward an immediate personal introduction, selected projects with filters, technical capabilities and a compact about section. Outdated article placeholders, invented career statistics and obsolete project descriptions are not reused.

## Functionality / accessibility

- Responsive navigation, keyboard focus, light/dark theme, accessible icon controls, filter state announcements via `aria-pressed`.
- Reduced-motion support, short reveal effects and no forced loader, parallax or scroll-jacking.
- Project cards link to real projects; **their previews are illustrative placeholders**, not screenshots.
