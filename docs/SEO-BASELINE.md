# SEO & AEO — baseline

الدومين الرسمي: https://engelyas.com/

- الاسم: إلياس الشعيبي / Elyas Al Shaebi.
- 5 صفحات أساسية في sitemap: الرئيسية وأقسام الأعمال الأربعة.
- HTML ثابت لكل الزوار، Schema.org JSON-LD، canonical، OG، Twitter Cards، favicon، 404.
- لا روابط خارجية للمشاريع في المعرض. لا تقييمات أو ادعاءات غير موثقة.
- robots يسمح للزواحف العامة؛ لا يوجد حظر خاص بمحركات إجابات الذكاء الاصطناعي. لا ضمان للفهرسة أو الترتيب أو الاستشهاد.

## Search Console
تعذر جلب بيانات الملكية في 27 نوفمبر 2026 بسبب انتهاء اشتراك GSC Wizard. هذه ليست نتيجة تفيد عدم فهرسة الموقع.
1. تحقق من ملكية engelyas.com على https://search.google.com/search-console/ (DNS TXT أو خاصية URL prefix حسب الحاجة).
2. أرسل https://engelyas.com/sitemap.xml.
3. افحص الصفحة الرئيسية وصفحات الأعمال الأربع في URL Inspection، واطلب الفهرسة للصفحات المهمة بعد التحقق المباشر.
4. تابع الأداء والاستعلامات ومشاكل الفهرسة؛ قارِن البيانات الفعلية لا مجرد بحث site:.
