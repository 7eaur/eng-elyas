# ELYAS AL SHAEBI — حزمة الهوية الموحدة V2

هذه الحزمة تجمع **الهوية البصرية الأساسية المعتمدة بعد فحص QA** و**أصول الويب الشفافة الجاهزة** في ملف واحد، دون استبدال أو تغيير الملفات الأصلية داخل الحزمتين.

## المجلدات

- `ELYAS_Personal_Identity_v2_QA_REVIEWED/` — أصول الشعار المتجهة، النسخ الرئيسية والثانوية، الهوية المعتمدة، الأيقونات، ملف الحركة، دليل الهوية العربي وتقرير المراجعة.
- `ELYAS_V2_WEB_ASSETS_2026-11-04/` — شعارات وأيقونات SVG/PNG/WebP جاهزة للويب، `public/brand/` وملفات إعدادات المطور (`developer/`) وصور مشاركة الروابط والنسخ الشفافة.

## إرشاد مهم

- **مرجع الهوية الأساسي:** راجع ملف الدليل في `00_GUIDELINES/` داخل مجلد الهوية؛ مصدر الشعار قابل للتحرير في `01_VECTOR_MASTERS/`.
- **للموقع:** ابدأ من `ELYAS_V2_WEB_ASSETS_2026-11-04/README_AR.md` وانسخ الأصول الملائمة إلى مشروعك، مع تحديث روابط النطاق في إعدادات المشاركة عند النشر.
- لم تُعدّل الملفات أو الألوان أو الأشكال أثناء هذا الدمج؛ ستجد النسخ المنفصلة للهوية والويب كما كانت.
- `MANIFEST_SHA256.json` يسجل بصمات SHA-256 لجميع الملفات داخل الحزمة للتحقق من سلامتها.
